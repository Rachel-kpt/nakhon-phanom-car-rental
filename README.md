# ระบบจองเช่ารถ (Car Rental Booking System)

เว็บแอปพลิเคชันระบบจองเช่ารถ พร้อมหน้าแอดมินปรับแต่งได้ และลิงก์แจ้งเตือนผ่าน LINE / WhatsApp

## วิธีใช้งาน

1. เปิดไฟล์ `index.html` ในเบราว์เซอร์ (Chrome, Safari, Edge ฯลฯ)
2. หน้าหลักจะแสดงรายการรถให้เช่า สามารถจองได้ทันที
3. เมื่อจองสำเร็จ จะมีปุ่ม **แจ้งผ่าน LINE** และ **แจ้งผ่าน WhatsApp** เพื่อส่งข้อความแจ้งเตือนไปยังเจ้าของรถ

## ระบบหลังบ้าน (แอดมิน)

1. เปิดไฟล์ `admin.html`
2. รหัสผ่านเริ่มต้น: **admin123**
3. สามารถทำสิ่งต่อไปนี้ได้:
   - ดูแดชบอร์ดและสถิติ
   - เพิ่ม / แก้ไข / ลบ รถ
   - ดูรายการจอง และกดแจ้งเตือนผ่าน LINE/WhatsApp
   - ตั้งค่าเว็บไซต์ทั้งหมด:
     - ชื่อบริษัท, สโลแกน, เกี่ยวกับเรา
     - สีหลัก / สีรอง (ธีมสี)
     - เบอร์ WhatsApp ของเจ้าของรถ
     - LINE ID
     - โลโก้, เบอร์โทร, อีเมล
     - เปลี่ยนรหัสผ่านแอดมิน

## วิธีติดตั้งบนมือถือ (PWA)

1. เปิดเว็บในเบราว์เซอร์มือถือ (Chrome / Safari)
2. กดเมนู → **Add to Home Screen** หรือ **เพิ่มไปที่หน้าจอหลัก**
3. จะได้ไอคอนแอปบนมือถือ เปิดใช้ได้เหมือนแอปจริง

## สำเนาการจอง

หลังจองสำเร็จ ผู้จองสามารถกด **ดาวน์โหลดสำเนาการจอง** เพื่อรับไฟล์ **PDF** ยืนยันไปแสดงต่อเจ้าของรถได้

ข้อมูลการจองจะถูกบันทึกอัตโนมัติ และแอดมินสามารถดูได้ในระบบหลังบ้าน พร้อมลิงก์แจ้งเตือน LINE / WhatsApp

- ดีไซน์สวยงาม ดูสบายตา รองรับมือถือ
- บันทึกข้อมูลในเบราว์เซอร์ (localStorage) ไม่ต้องติดตั้งเซิร์ฟเวอร์
- ลิงก์แจ้งเตือนพร้อมข้อความรายละเอียดการจองอัตโนมัติ
- ปรับแต่งหน้าเว็บได้ตามใจผ่านระบบแอดมิน

## หมายเหตุ

- ข้อมูลทั้งหมดเก็บในเบราว์เซอร์เครื่องนั้น หากต้องการใช้ข้ามเครื่องหรือหลายคน ควรอัปโหลดขึ้นโฮสติ้ง (เช่น Netlify, Vercel, หรือโฮสต์ทั่วไป) หรือเพิ่ม backend จริง
- ลิงก์ LINE จะเปิดแอป LINE พร้อมข้อความที่เตรียมไว้ สามารถเลือกส่งให้เจ้าของรถได้
- ลิงก์ WhatsApp จะเปิดแชทกับเบอร์ที่ตั้งไว้ในระบบแอดมิน
